# Template SPA API React

Template for UI Dashboard with React Vite environment and integrated with mock API.

---

## Tech Stack

- **Frontend:** React, Vite, Ant Design, Sass, React Query
- **Frontend State Management:** Zustand
- **Frontend Testing Libary:** React Testing Library, Playwright

---

## Getting Started

```bash
# 1. Clone
git clone https://github.com/angga-prasetyo/template-SPA-API-React.git
cd template-SPA-API-React

# 2. Install dependencies
pnpm install

# 3. Setup env
cp .env.example .env

# 4. Run UI: development environment
pnpm start

# 5. Run UI: production environment
pnpm build
pnpm serve

# 6. Run ESLint
pnpm lint

# 7. Run Unit Tests
pnpm coverage

# 8. Run E2E Tests
pnpm e2e

# 9. Run ESLint, Unit Tests, and E2E Tests
pnpm test
```

> Requires: Node.js v22.17.1+

## Features

- Login Page with mock API Integration
- Register Page (UI only)
- Forgot Password Page (UI only)
- Home Page (UI only)
- Products Page (UI only)
- Users Page with mock API Integration
- Details User Page with mock API Integration
- Create Edit User Page (UI only)
- Settings Sidebar with: Toggle Darkmode/Lightmode and Logout Function
- Navigation Sidebar
- Mobile Responsive
